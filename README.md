# AegisFin AI (에이지스핀 AI)
**시공간 그래프 신경망(T-GNN) 기반 실시간 이상거래탐지(FDS) 및 농생명·소상공인 설명가능 대안신용평가(XAI-ACS) AI 금융 플랫폼**

- **Live Demo (GitHub Pages)**: https://kevin9327.github.io/aegisfin-ai/
- **Author**: 소병권 (Byungkwon So)
- **Key Features**:
  1. **Temporal Graph Neural Network (T-GNN) Fraud Topology**: 3분 내 다단계 대포통장·보이스피싱 순환 세탁 링 실시간 탐지 및 자율 서킷브레이커 지급정지 시뮬레이션
  2. **Explainable Alternative Credit Scoring (XAI-ACS)**: 전북 농생명(김제 스마트팜, 익산 식품클러스터)·소상공인(전주 한옥마을) 비금융 현금흐름·계절성 보정 기반 SHAP 기여도 산출 및 중금리 절감 시뮬레이터
